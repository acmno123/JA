# 日語無盡特訓 · JA

N5 → N1 的日文 JLPT 闖關特訓，純前端、無需安裝，可直接部署到 GitHub Pages。

## 功能

- **登入／註冊**：信箱與暱稱註冊，密碼以 SHA-256 雜湊保存，支援自動登入。
- **新手教學**：首次登入自動導覽，之後可隨時從 ❓ 重新觀看。
- **闖關測驗**：選擇題、單字題、連線配對三種題型，每關 5 題。
- **愛心與連擊**：答錯扣一顆愛心，連續答對累積連擊，並有 XP 與等級紀錄。
- **錯題本**：答錯題目自動收錄，答對即移除，可集中複習。
- **語音朗讀**：題目、例句與完整句子都能聽發音，可調整語速與日文聲音。
- **語音作答**：按「語音作答」唸出選項即可作答，也可開啟自動語音作答。
- **跟讀評分**：每句都可以跟讀，系統依相似度給分，70 分以上算通過。
- **鍵盤操作**：1–4 選擇、Enter 繼續、V 語音作答、Esc 關閉視窗。
- **外觀**：綠色 Duolingo 風格，支援自動、淺色、深色三種主題，手機版已最佳化。
- **音效與靜音**：答對答錯有音效，可一鍵靜音。

## 執行方式

1. 直接用瀏覽器開啟 `index.html`，或
2. 把整個資料夾推到 GitHub，到 Settings → Pages 啟用（Workflow 已內建，`.github/workflows/static.yml`）。

> 語音辨識（跟讀、語音作答）建議使用 **Chrome** 或 **Edge**，並在第一次使用時允許麥克風權限。語音功能需要在 https 或 localhost 下才能正常使用。

## 檔案結構

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面結構：登入、主畫面、設定與教學彈窗 |
| `style.css` | 介面樣式、深色模式、動畫與響應式排版 |
| `data.js` | 題庫（N5–N1 的知識點與題目） |
| `storage.js` | 本機儲存封裝（localStorage，失敗時退回記憶體） |
| `sound.js` | 答對與答錯音效（Web Audio） |
| `tts.js` | 語音朗讀（語速、聲音、靜音） |
| `stt.js` | 語音辨識與發音相似度評分 |
| `app.js` | 主程式：闖關、錯題本、語音作答、跟讀、教學與設定 |
| `auth.js` | 登入與註冊 |

## 題庫格式

在 `data.js` 新增題目即可。選擇題需要 `options` 與 `ans`（答案必須在選項中），配對題使用 `pairs`。`speak` 是作答前可朗讀的內容，`full` 是作答後朗讀的完整句子。

## 注意事項

- 帳號與進度保存在瀏覽器的 localStorage 中，屬於本機資料，清除瀏覽器資料會一併清除。
- 這是前端展示用的帳號系統，並不具備伺服器端的安全性。若要多人使用並跨裝置同步，需要接後端服務。
- 發音評分是以文字相似度計算，漢字與假名混用時（例如「食べる」與「たべる」）分數會偏低。
